## What actual public source is missing

F4's first precommitted eight SEC ticker/venue associations returned eight
single current OpenFIGI `shareClassFIGI` common-stock reference candidates.
The reference provider reports security metadata but does **not** certify the
issuer's SEC CIK. An issuer's original SEC 10-K registration of stock under
Section 12(b) can provide a stronger *issuer-declared* security class,
original ticker and exchange cross-check, though it still does not prove
the exact FIGI/CUSIP, share-class-specific share count, historical
investment membership or an issuer's valuation.

The main original SEC instrument-source audit therefore:

1. Reuses the exact existing two official Nasdaq listing directories and
   current SEC ticker map. The SHA256 preselection domain and **same first
   eight SEC CIKs** from F4 are pinned by original CIK commitment
   `caa63b8763c38ae04e911ed05f7baaba086722062b5ba0d134c0b0082c21d972`.
   Any change to those eight is **HOLD**, never quietly resampled.
2. Uses the authentic `data.sec.gov/submissions/CIK{cik:010d}.json`
   original source for each included issuer, strictly same SEC CIK,
   current reporting ledger, one latest own 10-K fiscal end and conservative
   two-weekday filing lag. No 10-K/A substitution, stale annual 10-K,
   conflicting latest fiscal year or invented accession.
3. Reuses the *existing* independently verified P4U historical SEC
   10-K **filing-index and primary-document parser** rather than
   writing another HTML table extractor. Request only one official
   same-accession 10-K index plus the one document explicitly listed in
   its original SEC index, bounded to 2 MB + 32 MB per issuer and verified
   URL/filename, under already configured SEC fair-use requester identity.
   This is not a second OpenFIGI POST or an access to investor brokerage.
4. A candidate requires **one** original 12(b) plain-common class row
   with an independently stated matching ticker and matching exchange.
   Multiple plain-common rows, absent/mismatched ticker, preferred/warrant,
   12(g)-only evidence, Cboe/IEX unsupported 12(b) parser, out-of-time filing,
   original source inaccessible and ambiguous original accession are
   all separately counted HOLD. Do not pick an easier company in place
   of a failed frozen eight CIK.
5. Publish **only** source-state category counts over the original eight,
   original document hash commitment, UTC receipt, F4 cohort commitment,
   and constants forbidding class-specific market cap, FIGI-CIK identity
   proof, historical investable backtest and LIVE release. Never publish
   names, CIKs, tickers, accession IDs, document paths, filing contents,
   individual FIGIs or original SEC requester identity.

supporting the current symbol/class/venue, not an independently

## Authentic 12:06 UTC archive index result and bounded iXBRL parser hypothesis

The protected main-only original source [run #43017414953](https://github.com/nicobouch97/fund100-research/actions/runs/43017414953)
completed with the same frozen eight original F4 CIKs. It distinguished
**7** `ORIGINAL_SEC_ARCHIVE_PRIMARY_INDEX_UNSAFE_DOCUMENT_HOLD` and
**1** `NO_RECENT_ASOF_ELIGIBLE_OWN_10K_HOLD`. No original issuer-class
ticker/venue confirmation. No SEC 403/429 source failure was reported
among the seven: the first-party original filing-index document row
did not fit the older 2017-oriented P4U filename grammar.

An independently reviewed *public, unrelated* modern official SEC 2025
filing index illustrates `v-20250930.htm  iXBRL` in the document cell,
where the anchor opens an official SEC `/ix?doc=/Archives/.../v-20250930.htm`
viewer rather than linking directly to the original `.htm` URL:
https://www.sec.gov/Archives/edgar/data/1403161/000140316125000089/0001403161-25-000089-index.htm

The safety-preserving hypothesis is that the current archive index
places `iXBRL` decorative text *after* an otherwise safe original
filename, and the trusted official SEC viewer query is a wrapper
around the exact same underlying original SEC archived primary file.
This is **not yet proof** that all seven F4 cohort filings have the
same formatting; the next source run must establish actual outcomes.

The minimal shared original P4U parser change supports only a literal
trailing `iXBRL` marker and a viewer reference whose **single decoded
`doc` query equals the independently constructed original
same-CIK/same-accession/same-document canonical URL**. It still
rejects cross-host, HTTP downgrade, other filing, traversal,
additional parameters, duplicate queries, fragments, unexpected
cell text and unapproved filenames. The viewer itself is *never*
downloaded or followed; only the exact canonical primary SEC
document gets one bounded original GET.

P4U's original historic 2017 direct-filing behavior and all
unrelated research paths must continue to pass their existing
adversarial tests. The F5 main-only research workflow now explicitly
runs P4U's parser tests and retriggers on these code changes.
A positive 12(b) class result remains issuer-declared *review only*;
neither a completed original 10-K receipt nor the external FIGI
reference independently certifies a legal CIK-to-FIGI ownership bridge,
class shares, vintage returns, market cap, undervaluation, first
ACWI SELL or any trading release.
